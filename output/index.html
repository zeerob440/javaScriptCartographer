alert.js

alert.js is a program local to the folder output. The output folder contains alert.js and output/index.html. alert.js is located in the head element of this page. Since alert.js is invoked from a separate file from the html, the src is located inside the opening script tag, in the head of this page. It is best practice to invoke js scripts from external sources than directly within the html to maintain good separation of concerns.

alert.js example

console.log('From the Console: Hello, javaScriptCartographer!');
alert('Hello, javaScriptCartographer!');

alert

alert is used to program a popup on a website. Such as: alert('Hello, javaScriptCartographer!');

console.log

console.log is used to print to the browser console. Such as: console.log('From the Console: Hello, javaScriptCartographer!');
